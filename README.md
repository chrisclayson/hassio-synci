# hassio-synci

Home Assistant Plugin for synci.io

> [!CAUTION]
> Very, very alpha ... created largely for my own purposes, but sharing anyway. In no way is this
> integration extensively tested or guaranteed to work.

## Details

I created this integration partly as a way of learning how to build Home Assistant integrations but also because
none of the existing Open Banking based integrations suited me due to lack of support for my (UK based) bank accounts.

I discovered [synci.io,](https://synci.io) and it supported the majority of the banks I was interested in and was
reasonably priced with a well-documented, and easy to use, API open to all its subscribers.
